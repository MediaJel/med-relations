## Hotfixes

### For prisma6 client connection error

Introduces connection resiliency for Prisma v6 database operations, automatically retrying failed connections to reduce service disruptions caused by transient database connectivity issues.

### AWS SDK on multipart upload

Adds a shared retry mechanism to all S3 multipart upload operations, improving upload reliability when write operations encounter transient network or service failures.

### Restore All Lost Pagination Page-Size Selector Functionality

Removes a global CSS rule that was inadvertently hiding the page-size selector on every table throughout the app, restoring users' ability to choose how many rows are displayed per page.

### Add 30s timeout/maxWait to campaignReport $transaction

Adds a 30-second timeout to the Prisma interactive transaction in the editorial job, preventing it from hanging indefinitely and eliminating "transaction already closed" (P2028) errors that were causing job failures.

### Guard undefined GA4 OAuth account instead of crashing

Adds a null guard in the SEO job so that organizations without a connected GA4 account are skipped gracefully instead of crashing with a destructuring TypeError, fixing nine recurring failed jobs.

### Stop 404 retry storm that hit the 1h job timeout

Prevents the scrape-publisher job from endlessly retrying 404 responses that are expected to return no data, stopping the resulting retry storm that was causing the job to hit its one-hour Bull timeout across twenty failed runs.

### Gate transaction Impressions/Transactions columns by advertiser level

On the campaign details Transactions tab (V2), the Impressions and Transactions columns on the Publishers and Creatives tables are now shown only when the campaign is at the advertiser level, ensuring these metrics appear only where they are meaningful.

### Chunk large S3 report and stop masking the real error

Fixes the editorial-consolidate job crashing with a "string too large" error on oversized reports by splitting the S3 upload into chunks, and surfaces the real underlying error instead of swallowing failures silently as null.

### Bump CircleCI Node image to 20.19.0 to fix node-expat native build

Upgrades the CircleCI executor's Node.js image from 20.11.0 to 20.19.0 so that native packages requiring Node ≥20.15 (such as node-gyp@13's undici dependency) compile correctly during CI builds.

### Pin global node-gyp@11.5.0 in service Dockerfiles

Pins the global node-gyp installation to version 11.5.0 in service Dockerfiles to prevent the unpinned bun base image from pulling node-gyp@13, which was shadowing the local devDependency and breaking native dependency builds inside containers.
